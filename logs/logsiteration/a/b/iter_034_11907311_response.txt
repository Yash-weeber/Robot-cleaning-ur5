```python
import math

N = 100                     # number of points you want
values = [round(50 * (1 - math.cos(2 * math.pi * i / (N-1))), 2)
          for i in range(N)]

print(values)
```

* `i / (N‑1)` gives a fraction that runs from 0 to 1 as `i` goes from 0 to 99.  
* Multiplying by `2π` turns that fraction into an angle that sweeps a full circle.  
* `cos(θ)` varies from +1 → ‑1 → +1 over one period.  
* `1 ‑ cos(θ)` therefore varies from 0 → 2 → 0.  
* Multiplying by 50 scales the range to **0 → 100**.  
* `round(..., 2)` limits the output to two decimal places (you can drop the rounding if you prefer the raw floating‑point values).
